# Обновление до 0.4.0

Сервер 0.2.5 обновлять не требуется. Сохраните %APPDATA%\LinkLAN\profile.dpapi:
в нём ключ устройства и сохранённые сети. Новый клиент сохраняет старые поля и
добавляет настройки окна, раскрытия сетей и автозапуска.

Установите LinkLAN-Setup-x64-v0.4.0.exe либо распакуйте portable ZIP целиком.
Если используете ZIP, сначала завершите старый клиент через «Выход». В 0.4.0
крестик скрывает окно в трей; он больше не означает завершение процесса.

При первом обычном запуске включается автозагрузка в трей. Переключатель находится
в «Система → Сервер и настройки». Для автозагрузки с правами Wintun используется
Планировщик Windows, без сохранения пароля. Portable-папку после настройки не удаляйте.

Адрес действующего сервера: https://linklan.lknet.ru:8191. Не убирайте порт.
Текущие серверные .env, Compose и сертификаты не требуют изменения.

Подробнее: [UI-0.4.0.md](UI-0.4.0.md).
