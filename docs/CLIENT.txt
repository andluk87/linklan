LinkLAN 0.2.5 — Windows 10/11 x64

Первое подключение
1. Распакуйте весь ZIP. LinkLAN.exe и wintun.dll должны лежать рядом.
2. Запустите LinkLAN.exe и разрешите запуск от имени администратора.
3. В запросе «LinkLAN — брандмауэр» нажмите «Да», чтобы разрешить входящий и
   исходящий трафик приложения и все протоколы через виртуальную сеть.
   Согласие сохраняется; при следующем запуске повторного вопроса нет.
   «Нет» продолжает запуск без новых разрешающих правил. Повторить запрос можно
   через «Система → Доступ через брандмауэр…».
4. Введите домен сервера, например linklan.lknet.ru, и нажмите «Подключиться».
   HTTPS и порт 443 выбираются автоматически. Email и пароль аккаунта не нужны.
   Если сервер работает на другом порту, укажите домен:порт.
5. Имя компьютера берётся из Windows. Изменить его и домен можно в меню
   «Система → Сервер и настройки…».

Создание сети и подключение друзей
6. На первом ПК нажмите «Создать сеть». Задайте имя сети, пароль от 12 символов
   и подтверждение. Вариант доступа по умолчанию — «По паролю».
7. На остальных ПК нажмите «Присоединиться». Введите то же имя и пароль.
   Все компьютеры должны использовать один домен сервера.
8. После создания/вступления VPN включается автоматически. Раскройте сеть,
   выберите другой компьютер, нажмите «Копировать IP» или «Ping».
9. Подключайтесь к игре или сервису по виртуальному IP другого компьютера.

Свой ПК и его IP находятся в верхней панели, а не в списке участников.
Слева от других компьютеров палочки возрастающей высоты показывают результат
настоящего ICMP через виртуальную сеть. Проверка выполняется примерно раз в
4 секунды, только для подключённой сети:
  четыре зелёных — задержка до 50 мс;
  три зелёных — до 150 мс;
  две зелёных — до 300 мс;
  одна зелёная — выше 300 мс;
  маленькая красная — ответа ICMP нет;
  серые — сеть выключена или проверка ещё не выполнена.
Заблокированный ICMP тоже даёт красный индикатор. Кнопка Ping делает три
проверки выбранного ПК и показывает ответы и задержку.

Кнопка ON/OFF управляет подключением выбранной сети. Двойной щелчок по сети
переключает подключение. Правый щелчок по сети или компьютеру открывает действия:
приглашение, выход из сети, сведения, удаление/блокировка/подтверждение участника
(последние действия доступны владельцу). По коду приглашения можно вступить,
оставив имя сети и пароль пустыми.

В настройках есть светлая/тёмная тема и подключение последней сети при запуске.
Сохраняется несколько сетей; одновременно активна одна. Трафик IPv4: ICMP, TCP
и UDP. Автоматический поиск LAN-серверов через broadcast/multicast пока не
поддерживается. После согласия правила виртуальной сети действуют на все
протоколы, но только на свой адаптер, локальный IP и адреса своей подсети.
При отключении сети правила адаптера удаляются. Брандмауэр Windows остаётся
включённым. Серверные UDP-порты определяет администратор (например, 13478/51820).

Обновление
Для клиента 0.2.5 подходит работающий API 0.2.0: обновлять сервер не обязательно.
Закройте старый клиент и замените все файлы файлами нового ZIP.
Сохраните %APPDATA%\LinkLAN\profile.dpapi и используйте тот же Windows-профиль
и адрес сервера. Сети, ключ устройства и права владельца сохраняются.
При переходе с 0.1.0 сначала обновите API минимум до 0.2.0. Старый ключ того же
сервера переносится автоматически. Не удаляйте профиль для повторного входа.
У каждого компьютера свой ключ; копировать профиль на другой ПК не нужно.
Ключи защищены Windows DPAPI. Журнал: %APPDATA%\LinkLAN\client.log.

HTTP допускается для localhost. Для изолированной тестовой LAN есть запуск
LinkLAN.exe --allow-http (настройка действует только в этом запуске).

В этой тестовой сборке ключ подписи обновлений не задан: обновление вручную
из нового ZIP. LinkLAN.exe пока не имеет Authenticode-подписи издателя.
Wintun — официальный подписанный драйвер; его ZIP проверяется по SHA-256
при сборке. Проверки на реальных Windows 10/11 и разных NAT ещё необходимы.
Инструкция обновления проекта: docs/UPGRADE-0.2.5.md в архиве исходников.
