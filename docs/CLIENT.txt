LinkLAN 0.7.0 — Windows 10/11 x64, C# / WPF + Go

Установка и обновление
Используйте LinkLAN-Setup-x64-v0.7.0.exe либо распакуйте весь portable ZIP.
Рядом с LinkLAN.exe должны оставаться все DLL, LinkLAN-engine.exe и wintun.dll.
.NET включён в пакет, отдельная установка не требуется.
Не удаляйте %APPDATA%\LinkLAN\profile.dpapi: ключ устройства и сети сохраняются.
Для обновления интерфейса сервер обновлять не нужно (VPN: API >=0.2.0).

Запуск
Запустите LinkLAN.exe и подтвердите UAC. Если окно скрыто, откройте его через
значок в трее либо запустите LinkLAN.exe --show. «Система → Настройки → Сервер»:
укажите linklan.lknet.ru:8191 или свой адрес API, имя компьютера и сохраните.
«Система → Исключения брандмауэра» разрешает трафик виртуальной сети.

«Сеть → Создать сеть»: имя и пароль от 12 символов с подтверждением, либо
доступ по приглашению. На другом компьютере выберите «Присоединиться к сети».
Кнопка питания подключает выбранную сеть, повторное нажатие отключает VPN.
Одновременно работает одна сеть. Индикатор задержки основан на настоящем ICMP:
четыре зелёных до 50 мс, три до 100 мс, две жёлтых до 200 мс, одна красная выше.
Серые означают отсутствие измерения или ответа. Статус API и ICMP различаются.
Правой кнопкой на компьютере: IP, пинг, общие папки, RDP, свойства.
Владелец сети может управлять участниками через контекстное меню.

Настройки применяются сразу: светлая/тёмная/Windows, русский/English,
автоподключение, автозагрузка Windows, запуск в трее, уведомления и звук.
Закрытие и сворачивание оставляют VPN в трее без кнопки на панели задач.
«Система → Выход» завершает оболочку и Go-движок.
Админ-панель открывается в браузере и запрашивает токен (API >=0.5.0).
Обновления открывают GitHub Releases; заменяйте весь пакет, а не один EXE.
