# LinkLAN 0.5.1

Исправлена ошибка «XML syntax error … invalid UTF-8» при сохранении настроек и повторном включении автозагрузки. schtasks.exe может возвращать XML в системной OEM-кодировке, несмотря на декларацию UTF-16. Теперь распознаются UTF-16 LE/BE, UTF-8 и OEM Windows; кириллические пути сохраняются после декодирования. Проверка владельца задания сохранена.

Установите LinkLAN-Setup-x64-v0.5.1.exe поверх текущей версии. Удалять профиль, сети или задание вручную не требуется. Сервер обновлять не нужно.

Добавлены проверки русских описаний/путей в семи форматах вывода и повторного чтения существующего задания на Windows.
