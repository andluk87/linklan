# LinkLAN 0.7.3 — компактная компоновка

Предыдущие числовые проверки карточки не отражали проблему всего окна: старая
сохранённая ширина 571 DIP делала список слишком растянутым, а выделение сети
показывалось широкой синей полосой. На масштабе 175% эти же пропорции увеличивались.

- Новая исходная ширина — 360 DIP, минимальная — 320. Старые размеры переходят
  на компактную ширину один раз. После этого ручное изменение ширины сохраняется.
  Высота, положение, тема, профиль и сети сохраняются.
- Заголовок сети не получает сплошную синюю заливку при выборе. Компьютеры
  сохраняют небольшое скруглённое выделение.
- Шрифт списка увеличен до 12 DIP, строка — до 22. Колонка IP — 104 DIP с
  выравниванием слева, длинные имена сокращаются. Текст форматируется в Display mode.
- Собственная карточка и верхние отступы компактнее: кнопка 54 DIP, имя 14 DIP,
  размеры меню и логотипа согласованы с остальными элементами.

## Проверка

Windows CI проверяет 30 сочетаний темы, ширины 320/360/420 и масштаба
100/125/150/175/200%. Это моделирование масштаба WPF, а не физическая смена DPI
монитора. Перенос между настоящими мониторами остаётся ручной проверкой.

Отдельный сценарий формирует реальные WPF-снимки небольшой сети с выбранным
заголовком и выбранным компьютером, в двух темах при 100% и 175%. Изображения
включены в LinkLAN-UI-preview-v0.7.3.zip; перед публикацией они просматриваются.
Проверка профиля DPAPI подтверждает переход с ширины 571 на 360, сохранение
идентификатора/ключей и последующее восстановление выбранной ширины 420.

Пакет сначала собирается в черновик GitHub Release для визуальной проверки;
публикация выполняется после проверки и успешного релизного CI.
Сервер для изменения компоновки обновлять не требуется.
