# Проверка 0.2.3

Основа — исходники 0.2.1 из присланного update ZIP. Архивы 0.1.0 и 0.2.0
содержат более раннюю реализацию; повторные архивы 0.2.1 совпадают.
Исходники готового клиента 0.2.2 не предоставлены.

Проверено в текущей Linux-среде с Go 1.26.8:

- 37 Go-тестов, включая 5 интеграционных тестов с PostgreSQL: PASS, без пропусков.
- go vet: PASS; Windows amd64 cross-build с версией 0.2.3: PASS.
- 2 Python-теста публикации: PASS (согласованность релиза, исключение секретов,
  получение актуального EXE из ZIP, повторный запуск).
- Docker API/relay build и запуск PostgreSQL, Redis, API, relay, Nginx: PASS.
- HTTP API health, регистрация через Nginx, страница сайта: PASS.
- Ответ STUN через опубликованный UDP 3478: PASS.
- compose.yml, compose.tls.yml, compose.api.yml: конфигурация корректна.
- API-only HTTPS gateway: health PASS, TLS-сертификат проверяется через локальный
  тестовый CA; /, /admin, /downloads закрыты (404), /api/metrics закрыт (403).

Windows GUI, Wintun и VPN между двумя Windows-ПК пока не проверены.
Загрузка официального Wintun в текущей среде требует разрешённых доменов
www.wintun.net и wintun.net. Готовый ZIP/NSIS и выполнение GitHub Actions
подтверждаются отдельно; наличие workflow не означает успешную удалённую сборку.
Документы BUILD-CHECK более ранних версий — исторические отчёты, не результаты
текущей проверки.
