# LinkLAN 0.7.1 — уточнение интерфейса по видеозаписям

Сравнены четыре записи: три показывают интерфейс Radmin VPN, последняя —
сравнение прежнего LinkLAN с Radmin. Бренд LinkLAN и существующие функции сохранены.

- Карточки сетей: увеличен промежуток между сетями, уменьшен отступ у компьютеров,
  выделение осталось скруглённым, отдельная колонка IP не меняет ширину.
- Меню стали плотнее; клавиатурный фокус списка не рисует стандартную прямоугольную рамку.
- «Изменить имя», двойной щелчок по своему имени и F2 открывают поле в собственной
  карточке. Enter сохраняет, Escape отменяет. Новое имя подтверждается Go-движком;
  устройство, ключ и текущий VPN-сеанс не заменяются. При ошибке ввод остаётся открытым.
- Настройки: компактное окно, светлая/тёмная боковая панель с векторными значками,
  короткие названия разделов, немедленный выбор темы и языка. Заголовок и кнопка
  закрытия переводятся вместе с остальными элементами. Ошибка сохранения возвращает
  переключатель к прежнему значению.
- Свойства компьютера: три блока — устройство, сеть, соединение. Значения можно
  выделять и копировать; задержка и тип канала берутся из фактического состояния.

.NET включён в пакет. Обновляйте полным установщиком или распаковывайте весь ZIP.
Существующий DPAPI-профиль сохраняется. Для этих правок сервер обновлять не нужно.

Windows CI сохраняет снимки основного окна в 16 сочетаниях ширины/темы/масштаба,
настроек, меню, свойств и редактирования имени. Проверяются отмена/пустое имя/
сохранение имени без смены состояния подключения. Go-тест проверяет подпись
запроса переименования и сохранение ключа и идентификатора устройства.
