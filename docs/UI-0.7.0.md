# LinkLAN 0.7.0 — C# / WPF

Основной Windows-интерфейс перенесён с ручной Win32/GDI-отрисовки на WPF.
Кнопка питания имеет круговую рамку фокуса. Список использует стабильные ID
компьютеров и отдельную колонку IP; WPF перерисовывает элементы при изменении
размера окна. Меню, поля, переключатели, диалоги и подсказки используют общую тему.

Сохранены светлая, тёмная и системная темы, русский/English, шесть страниц
настроек, управление сетями и участниками, свойства, Ping, общие папки и RDP.
Закрытие и сворачивание прячут окно в трей; «Выход» отключает VPN и завершает
движок. Повторный запуск возвращает существующее окно. При отсутствии трея
остаётся обычное свёрнутое окно. Автозагрузка запускает оболочку WPF от текущего
пользователя через существующее задание Планировщика Windows.

`LinkLAN.exe` — C#/WPF. `LinkLAN-engine.exe` — Go: DPAPI, API, Wintun,
шифрование, маршруты, переподключение и брандмауэр. Обмен — JSON через унаследованные
stdin/stdout, без нового сетевого порта. Интерфейс получает только публичное
состояние: приватные ключи, refresh/access-токены и закреплённые ключи профиля
не передаются. Именованный канал оболочки разрешён только текущему пользователю
и принимает только команды показа окна и завершения программы.

Пакет включает .NET 10 для Windows x64; устанавливать .NET отдельно не нужно.
Распаковывайте **весь ZIP**, либо используйте Setup. Один `LinkLAN.exe` без DLL
новой оболочки работать не будет. Обновление — через полную установку или ZIP,
кнопка проверки обновлений открывает GitHub Releases.

Существующий `%APPDATA%\LinkLAN\profile.dpapi` читается тем же Go-кодом.
Не удаляйте его: там идентификатор устройства, сети и права владельца. Сервер
для переноса интерфейса обновлять не требуется; VPN совместим с API >=0.2.0,
админ-панель требует API >=0.5.0. Панель открывается в браузере и сама запрашивает
административный токен; он не добавляется к URL.

Проверки: unit-тесты Go для закрытого обмена и сохранения профиля; Windows CI
запускает фактические WPF-шаблоны, проверяет 16 сочетаний темы/ширины/масштаба,
повторное изменение размеров с попиксельным сравнением, настройки, переключение
языка и состояния питания. Скриншоты и отчёты доступны в артефакте Windows CI.
Проверка интерфейса использует явный автономный `--ui-check`, без создания
виртуального адаптера, сетевых запросов и записи рабочего профиля.

Сборка: Go 1.26.8, Python 3, .NET SDK 10.0.404, NSIS. На Linux:

```sh
python3 scripts/build-client.py --installer-image linklan-nsis
```

Версия берётся из `release-version`; имена ZIP и установщика содержат её.
