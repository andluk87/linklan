# LinkLAN 0.7.2 — карточка сети по образцу Radmin VPN

Сравнены два предоставленных фрагмента карточек LinkLAN и Radmin VPN.

- IP выровнены по левому краю отдельной колонки шириной 92 DIP: короткий адрес
  больше не уезжает вправо. Виртуальные IP LinkLAN не изменяются.
- Строки компьютеров — 20 DIP, шрифт имён/IP — Segoe UI 11; заголовок — 22 DIP,
  полужирный. Имена отключённых устройств остаются читаемыми.
- Скруглённое выделение отступает от краёв карточки; сигнальные полоски уменьшены,
  стрелка раскрытия сделана крупнее. Длинные имена по-прежнему сокращаются.

Изменения касаются представления. Движок, профиль, сети и сервер не меняются.
Windows CI проверяет ширину, левое выравнивание IP, размер текста, высоту строки
и перерисовку при четырёх масштабах в двух темах и двух размерах окна.
