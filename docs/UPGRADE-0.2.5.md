# Обновление до 0.2.5

Клиент собран из предоставленных исходников 0.2.1. Исходники готового клиента
0.2.2 отсутствовали; его дополнительные изменения интерфейса не восстановлены.
Серверный API остаётся совместимым с 0.2.0 и 0.2.1.

Закройте клиент и замените все файлы portable ZIP файлами нового
`LinkLAN-Windows-x64-v0.2.5.zip`. Сохраните `%APPDATA%\LinkLAN\profile.dpapi`,
используйте того же Windows-пользователя и тот же адрес сервера. Не копируйте
профиль на другой ПК и не удаляйте его для повторного подключения.

GitHub Actions проверяет Go-тесты с PostgreSQL, go vet и тесты упаковки, затем
создаёт ZIP, NSIS-установщик, исходники и update ZIP. Версия берётся из
`release-version`; все основные файлы включают её в имени. В 0.2.5 исправлена
запись команды удаления NSIS-установщика в реестре Windows.

API-only HTTPS на 8191 — необязательный режим, включаемый отдельно. Адрес клиента
в этом случае должен содержать порт: `YOUR_DOMAIN:8191`. В нём отсутствуют сайт
и загрузки, поэтому обновление ручное. Обычная серверная установка не меняется
автоматически при загрузке нового клиента или файлов на GitHub.

Подробнее: [RELEASES.md](RELEASES.md).

В Nginx исправлено обновление IP API после пересоздания контейнера. Это исправление
относится к серверной конфигурации: обновите файлы deploy/nginx и выполните
`docker compose exec web nginx -t && docker compose exec web nginx -s reload`.
Для режима TLS используется обновлённый tls.conf; режим API-only уже использует
динамический DNS. Профили клиентов и серверные данные не удаляются.
