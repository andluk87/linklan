# Обновление клиента LinkLAN до 0.6.0

Установите `LinkLAN-Setup-x64-v0.6.0.exe` поверх текущей версии. Установщик завершает работающий клиент перед заменой файлов. Не удаляйте `%APPDATA%\LinkLAN\profile.dpapi`: в нём остаются ключ устройства, сервер, сети, права и новые настройки. Для переносной версии выполните «Система → Выход» и замените весь комплект файлами нового ZIP.

Для этого редизайна сервер обновлять не требуется. Протокол, адресация и серверный API сохранены. Админ-панель использует существующий вход по токену и требует API 0.5.0 или новее; её развёртывание описано в UPGRADE-0.5.0.md.

Новые установки запускаются в светлой теме. Ранее сохранённая тема и размеры окна сохраняются. Для голубого оформления выберите **Система → Настройки → Тема → Светлая**. Свежий профиль использует размер 440×500; минимальный размер 250×350.

В настройках шесть разделов: тема, язык, дополнительно, уведомления, сервер и администрирование. Тема, язык и переключатели сохраняются сразу. У параметров сервера отдельная кнопка «Сохранить»; старое подключение сохраняется, пока новый сервер не ответит успешно. При ошибке форма остаётся открытой.

Автозапуск и запуск в трее настраиваются отдельно. Отключение «Запускать свёрнутым в трей» открывает окно при запуске задания входа Windows. Создание задания по-прежнему использует SID текущего пользователя, без сохранения пароля; исправление кодировки из 0.5.1 сохранено. Крестик главного окна скрывает его в трей, полное завершение — через меню «Выход».

Уведомления выводятся штатным механизмом Windows, могут быть без звука и учитывать состояние пользователя/режим «Фокус». Короткие переподключения подавляются; частота ограничена. При отсутствии системного трея приложение сохраняет видимое окно.

В меню «Сеть» остались создание и присоединение; операции конкретной сети находятся в её контекстном меню. Insert создаёт сеть, F5 обновляет список, Ctrl+C копирует IP выбранного участника. Приглашения, RDP, общие папки и журнал сохранены. Пункты несуществующего удалённого просмотра/файлового протокола не добавляются.

Если сборка не содержит ключа подписи автоматических обновлений, пункт «Проверить обновления» открывает официальный последний релиз GitHub. При наличии ключа сохранён механизм проверки и установки подписанных обновлений; проверка подписи не отключается.

Проверки и снимки: UI-0.6.0.md. Реальную работу VPN между физическими Windows-компьютерами, ограничения корпоративной Windows и переходы между физическими мониторами проверяйте в своей среде.
