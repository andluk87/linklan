# Проверки 0.2.5

Проект восстановлен из исходников 0.2.1. Двоичный клиент 0.2.2 не содержал исходников.

Проверки текущей среды:

- 37 Go-тестов прошли с PostgreSQL, без пропусков; go vet прошёл.
- 2 теста упаковки прошли: проверены целостность и версия manifest/ZIP,
  исключение секретов из источников, актуальный EXE и повторная публикация.
- Windows amd64 cross-build и Docker API/relay build прошли.
- Go 1.26.8 и официальный Wintun ZIP проверены по закреплённым SHA-256.
- Полная локальная сборка portable ZIP и NSIS 0.2.4 прошла; исправлены
  предупреждения о некорректной команде удаления. Формат сборки в 0.2.5 тот же.
- GitHub 0.2.4: тесты, сборка, Windows-установка, запись удаления в реестре,
  --self-test, --version и публикация Release прошли.
- Серверные PostgreSQL, Redis, API, relay и Nginx запущены. API health,
  регистрация через Nginx и главная страница проверены функциональными запросами.
- STUN ответил на запрос через опубликованный UDP-порт.
- API-only TLS gateway: сертификат проверен через локальный CA, health работает,
  /, /admin, /downloads возвращают 404, /api/metrics возвращает 403.
- Воспроизведён 502 после пересоздания API без перезапуска web. Исправлена
  конфигурация динамического DNS для обычного и TLS-прокси; повторное пересоздание
  API восстановило запросы без перезапуска web.

Выполнение и файлы GitHub Release 0.2.5 проверяются по текущему запуску Actions;
предыдущие результаты не заменяют новый запуск. Windows GUI, Wintun runtime,
связь между двумя реальными Windows-ПК и NAT остаются непроверенными.
